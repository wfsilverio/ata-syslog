Principal achado

A aba Dados gerais reúne identificação, valores, prazos e vigência, classificação, dados da contratação, produto contratado e PNCP, e o link do PNCP abre a página certa do contrato. O que reprova:

  • Não existe a seção Assinaturas (data limite, data da assinatura do contrato, Prorrogar Assinatura).
  • A Equipe não fica em Dados gerais: é uma aba à parte.

  • Obtido: a ficha não tem essa seção. A API ObterDadosGerais também não traz esses campos.

Agravante:

  • Sem o bloco, a Análise de Requisitos também não diz de onde vêm os dados. Não há tabela nem API mapeada para:
    • data limite;
    • data de assinatura do fornecedor;
    • prorrogação.
  • A task #22602 ([Back] Implementar integração API Dados Gerais) está em impediment, e o PBI tem o comentário "Estamos aguardando API do SISLOG". Hoje nem o backend sabe onde buscar esses campos.

Sugestão de classificação:

  • Tipo: requisito não implementado, por lacuna na especificação. Não é defeito de código.
  • Quem resolve: primeiro a Análise de Requisitos (Marcella) inclui o bloco Assinaturas, com a fonte de dados. Depois vêm o protótipo e o desenvolvimento.
